Retrieval evaluation harness

Information retrieval

I wrote eval_retrieval.py to compare three strategies on one shared query set: semantic search alone, hybrid BM25 and dense retrieval fused with Reciprocal Rank Fusion, and the same hybrid with a cross-encoder reranker.

The reranker won on accuracy, but its memory cost broke the 512 MB hosting budget. A modelling question became a documented production trade-off.

A research agent on LangGraph’s create_react_agent, with its tools served over the Model Context Protocol through langchain-mcp-adapters.

Groq handles inference, Tavily the web search and Qdrant the retrieval. LangSmith records every run, so a bad answer can be traced back to the tool call that caused it.
